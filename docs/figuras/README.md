# Figuras de la unidad

Directorio para figuras originales del curso y diagramas generados por sus
herramientas. No agregar imágenes escaneadas o extraídas del libro; citar su
número y edición en el material para que el alumnado las consulte en su
ejemplar.

Al publicar un archivo aquí, su URL raw será:

`https://raw.githubusercontent.com/ITH-MGL-MN/U5_derivadas_integrales_EDO/main/docs/figuras/<archivo>`
